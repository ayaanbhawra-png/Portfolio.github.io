Case Study

📘 TeachUs – Placement Management Portal

Think Monk Internship | UI/UX Design & Full Prototyping

🔍 Problem Statement
Traditional placement cells rely on spreadsheets & manual coordination causing inefficiency for students, TPO, and recruiters.
👥 User Research
Analyzed placement mechanisms across colleges; identified pain points of 500+ students, TPO dashboard needs, recruiter tracking.
📐 Design Process – Mobile-first strategy, converted desktop tables into card-based lists, role-based dashboards, bottom navigation, and built a design system of 40+ screens in Figma.
🎨 UI Highlights – Policy configuration screen (offer limits), application status badges, offer acceptance modals, real-time application tracking.
✅ Final Solution – Fully clickable prototype demonstrating end-to-end journey: student job discovery → apply → recruiter shortlisting → TPO analytics.
